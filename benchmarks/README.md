# Escalate benchmarks

This directory intentionally contains no claimed results yet.

Future measured runs will compare rules-only, Laya-only, and Laya plus deterministic routing on a versioned labeled dataset. Each result must record the dataset revision, hardware, provider/model revision, thresholds, random seed, and commands used.

Planned measures are category accuracy, routing accuracy, latency percentiles, calibration error, human-review rate, override rate, and inference cost. Measured artifacts—not invented showcase numbers—will be committed here.
